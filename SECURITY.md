# Security

Report a suspected BountyDeck vulnerability privately to the operator of the affected deployment. For a source-code issue, contact the repository maintainer privately through the hosting platform. Include the affected version and the impact. Keep credentials, evidence files and confidential report contents out of public issues.

The [deployment guide](DEPLOYMENT.md) describes production isolation, secret handling, image scanning and rollback. The [hardening report](HARDENING.md) lists verified controls and known limitations.
